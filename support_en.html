Color Cage

A Puzzle Game - Drag Blocks to Trap the Balls!

🎯 About the Game

Color Cage is a strategic puzzle game where you drag blocks to trap constantly moving colored balls. Separate all the balls by color within the time limit to win!

With simple yet addictive gameplay, anyone can enjoy this game easily, but higher levels require strategic thinking.

📖 How to Play

1. Touch and drag the blocks on the screen.

2. Move blocks to block the path of moving balls.

3. Trap balls of the same color in one area.

4. Separate all colors within the time limit to clear the level!
